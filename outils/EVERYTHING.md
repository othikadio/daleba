# Everything (HeyPuter) — logiciels libres, utilisables en ligne

Projet MIT : https://github.com/HeyPuter/everything — installé comme sous-module dans `outils/everything`.
Pour télécharger le code dans une session : `git submodule update --init --depth 1 outils/everything`, puis `cd outils/everything/src/<app> && npm install && npm run dev`.

**Le plus simple : ouvre les liens « En ligne » directement depuis ton téléphone.**
